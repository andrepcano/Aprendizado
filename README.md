# Aprendizado em Python

Repositório dedicado à prática e ao aprendizado de programação com Python, contendo exercícios de lógica, estruturas de controle e manipulação de dados.

## Conteúdos praticados

- Entrada e saída de dados
- Operadores aritméticos e condicionais
- Estruturas de decisão (`if`, `elif` e `else`)
- Laços de repetição (`for` e `while`)
- Tuplas e listas
- Validação de dados
- Pequenos simuladores, como caixa eletrônico, empréstimo e cadastro

## Estrutura do projeto

```text
.
├── Exercicios/       # 37 exercícios de Python
├── Exercicios GG/    # 46 exercícios do curso em andamento
├── testeIA.py        # Experimento inicial usando IA/Codex
└── .gitignore
```

## Como executar

1. Instale o Python 3.
2. Clone este repositório:

   ```bash
   git clone https://github.com/andrepcano/Aprendizado.git
   ```

3. Acesse a pasta e execute o exercício desejado:

   ```bash
   cd Aprendizado
   python "Exercicios GG/01_emprestimo.py"
   ```
